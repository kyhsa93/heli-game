# 헬기 조종

https://kyhsa93.github.io/heli-game/

브라우저에서 하는 헬기 조종 게임. 메뉴에서 두 가지 모드를 고른다.

- **AH-64 아파치 조종석** — 1인칭 3D 시뮬레이터(three.js). 탠덤 좌석의 뒷좌석(조종사석)에 앉아 콜렉티브·사이클릭·페달로 조종하고, MPD 두 화면(비행·전술 지도)과 헬멧 심볼(IHADSS)을 보며 보급품을 픽업 패드에서 목적지 패드까지 나른다.
- **측면 아케이드** — 옆에서 보는 2D. 줄에 매단 화물을 흔들리지 않게 내려놓는다.

## 조종석 조작

| 키 | 동작 |
| --- | --- |
| I | 엔진 시동 / 정지 |
| W / S | 콜렉티브 올리기 / 내리기 (놓아도 유지, Shift: 미세 조정) |
| 방향키 | 사이클릭 (기수 숙이기·들기, 좌우 기울이기) |
| A / D | 페달 (기수 좌우 회전) |
| 마우스 드래그 | 고개 돌리기 (C 또는 더블클릭: 정면) |
| V · U · M | 외부 시점 · 헬멧 심볼(IHADSS) · 소리 |
| R · Esc | 다시 시작 · 메뉴 |

게임패드(왼쪽 스틱 콜렉티브·페달, 오른쪽 스틱 사이클릭, A 시동, Y 시점)와 터치 가상 스틱도 지원한다.

- 착륙: 하강률 약 590 fpm 이하, 거의 멈춘 채로, 수평으로. 로터(지름 14.6 m)·나무·건물에 닿으면 추락.
- 헬멧 심볼 가운데의 선은 기체가 흘러가는 방향(호버 벡터)이다. 착륙 직전엔 이 선을 점으로 줄인다.
- 픽업 패드에 3초, 목적지 패드에 2초 머무르면 적재·하역. 연료는 H 패드에서 보급.
- 엔진이 꺼지면 콜렉티브를 내려 로터 회전수를 지키고(오토로테이션) 지면 직전에 올린다.

## 측면 아케이드 조작

▲/W/Space 상승 · ▼/S 하강 · ◀▶/A D 기울이기 · E 화물 고리 · R 재시작 · Esc 메뉴

## 앱으로 설치 (PWA)

브라우저 메뉴의 "앱 설치" 또는 "홈 화면에 추가"로 설치하면 전체 화면으로 실행된다. 서비스 워커는 아무것도 캐시하지 않고 모든 요청을 `cache: 'no-store'`로 네트워크에서 새로 받으므로, 앱을 열 때마다 항상 최신 버전이 뜬다(오프라인에서는 실행되지 않는다).

## 개발

React + TypeScript + Vite. `main`에 push하면 GitHub Actions가 테스트·빌드 후 Pages에 배포한다.

```sh
npm install
npm run dev     # 개발 서버
npm run check   # 타입체크 + 테스트 + 빌드
```

- `src/sim3d/` — 조종석 모드: 비행 물리·임무(`sim.ts`), 지형 생성(`terrain.ts`), three.js 장면(`scene.ts`), 아파치 기체·조종석 모델(`heliModel.ts`), MPD·EUFD·예비 계기(`instruments.ts`), 헬멧 심볼(`ihadss.ts`), 로터 소리(`audio.ts`), 입력(`input.ts`)
- `src/game/` — 측면 아케이드 모드의 물리·렌더
- `src/components/` — 메뉴와 각 모드의 React 화면
