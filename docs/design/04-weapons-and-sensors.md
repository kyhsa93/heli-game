# 04. 무장과 센서

이 장의 수치가 무장·센서 밸런스의 원본이다. 구현 시 `src/content/weapons.json`, `src/content/sensors.json`으로 옮긴다. 수치는 실제 제원을 참고해 **게임용으로 조정한 값**이다.

## 4.1 무장 탑재

- 스텁 윙 파일런 4개(좌외·좌내·우내·우외, 코드 ID `L2 L1 R1 R2`). 각 파일런에 하나를 단다: **헬파이어 발사대**(4발) / **로켓 포드**(19발) / 빈칸.
- 날개 끝에 **스팅어 발사대**(2발, 좌우 1개씩) 선택 (임무 9 해금).
- 기수 아래 **30mm 기관포**는 항상 장착, 탄약량만 선택(300/600/1,200발).
- 헬파이어 발사대에는 레이저형(`AGM-114K`)과 레이더형(`AGM-114L`, 임무 6 해금)을 **발사대 단위로** 섞어 달 수 있다.
- 무게 규칙은 03장 3.2절.
- 현재 외형 모델(`heliModel.ts`)은 안쪽 파일런에 헬파이어, 바깥쪽에 로켓 포드가 고정으로 그려져 있다. **로드아웃에 따라 파일런별로 메시를 켜고 끄도록** 바꾼다. 발사한 미사일·로켓은 메시에서 하나씩 사라져야 한다(조종석에서 옆을 보면 줄어든 게 보여야 한다, P1).

- **관통 등급 vs 장갑 등급**: 무장 관통 등급 < 표적 장갑 등급이면 피해 × 0.1. 같으면 × 1. 크면 × 1.2. (예: 30mm(2)는 전차(4)에 거의 무효 → 헬파이어가 필요. 이게 무장 선택의 이유다.)
- **탄도**: 기관포·로켓은 실제 탄체(발사체 엔티티)를 시뮬레이션한다. 중력 9.81, 항력 계수 `k`는 무장별(기관포 0.0012, 로켓 0.0006, 단위 1/m). 발사체는 물리 스텝마다 이동하고, 이동 선분과 지형·유닛 충돌을 검사한다(빠른 탄이 표적을 뚫고 지나가지 않게 선분 검사).
- **분산**: 기관포 원뿔 분산 5mrad(1km에서 반경 5m), 로켓 8mrad. 이동 중(속도 > 20kt)이면 × 1.5.

## 4.3 조준 흐름 (무장별)

플레이어는 조종사이자 사수(CPG) 역할을 겸한다. 실제로는 앞좌석 사수가 TADS를 다루지만, 게임에서는 **"TADS 모드"로 전환**하면 플레이어가 TADS를 직접 조작한다. TADS 모드 중에는 기체가 **자동 호버로 위치를 유지**한다(보조 설정과 무관한 규칙, 사수에게 조종을 맡겼다는 설정: "조종 인계").

### 기관포 — 헬멧 조준 (기본)
1. `무장 선택: 기관포` (키 `1`)
2. 기관포가 **플레이어 시선(마우스로 돌리는 머리 방향)을 따라** 회전한다. 짐벌 한계: 방위 ±86°, 고각 +11°/−60°. 한계 밖이면 IHADSS 조준점이 `X` 로 바뀐다.
3. IHADSS에 **기관포 조준점**(작은 십자)과 **탄착 예측점**(거리 추정 기반, 레이저 측거 시 정확)이 뜬다.
4. 발사(키 `Space` / 마우스 좌클릭 / 패드 RT). 연사 중에는 예광탄(5발에 1발)이 보인다.
5. 과열 없음. 탄약 소진 시 `GUN EMPTY`.

### 로켓 — 조향 큐
1. `무장 선택: 로켓` (키 `2`). 연사 수 전환(키 `2` 반복: 1 → 2 → 4).
2. 로켓은 기체 고정이다. IHADSS에 **로켓 조향 커서**(I자 모양)가 뜨고, 표적(TADS로 지정했거나 헬멧 시선이 가리키는 지점)까지의 방위·거리를 반영해 기체를 어디로 돌려야 하는지 보여 준다.
3. 거리에 맞게 기수를 들어 올리는 **고각 보정 큐**(수평 막대)가 커서와 겹치면 발사.
4. 로켓은 면 제압용이다. 보병·경차량·건물 무리에 강하다.
5. 구현 세부(M2-3): 방아쇠를 **누를 때마다** 선택한 연사 수만큼 0.1초 간격으로 나간다(누르고 있어도 한 번). 좌우 포드를 번갈아 쓴다. 발사관 이탈 60m/s에서 1.1초 추진해 약 700m/s까지 가속한 뒤 탄도 비행(`weapons.json`의 `launchSpeed`·`burnTime`·`thrust`). 최소 사거리 300m 안에서 맞으면 신관이 무장되지 않아 피해가 없다(기관포는 0m). IHADSS에는 기체 고정 조준원(작은 원), 표적 지점(작은 십자), I자 커서(방위), 수평 막대(고각), 표적 거리, `RKT 남은수 x연사` 상태가 뜬다. 거리 300m 미만은 `MIN`, 유효 사거리 3,000m 초과는 `MAX`.

### 헬파이어 레이저 — LOBL / LOAL
1. `무장 선택: 헬파이어` (키 `3`). TADS 모드로 전환(키 `T`).
2. TADS 화면에서 조준 십자로 표적을 겨누고 **레이저 발사**(키 `L`, 누르고 있으면 계속 지시). 레이저 측거로 거리가 뜬다.
3. **LOBL(발사 전 잠금)**: 레이저가 표적에 있고 거리 ≤ 8,000m이면 미사일 탐색기가 잠금 → IHADSS/TADS에 `LOBL` 표시와 **잠금 톤** → 발사. 미사일은 명중까지 레이저 점을 따라간다. **레이저를 끊거나 표적이 가시선 밖으로 가면 미사일은 마지막 점으로 날아가 빗나간다.**
4. **LOAL(발사 후 잠금)**: 능선 뒤에 숨은 채 발사하고(미사일은 위로 솟았다가 내려옴), 떠올라 레이저를 비추면 그때 잠근다. 가시선 노출 시간을 줄이는 고급 전술. 발사 후 레이저 지시까지 허용 시간 10초.
5. 윙맨이나 지상 통제관이 레이저를 비추는 **원격 지시** 표적도 있다(임무 스크립트, `remoteLaser` 이벤트). 이때는 플레이어가 가시선 없이 쏠 수 있다.

### 헬파이어 레이더 — FCR 발사 후 망각
1. FCR 스캔(키 `R`, 한 번 돌리는 데 3초, 이동 중에도 가능). 스캔 동안 레이더 전파를 내므로 **적 RWR 유닛(SAM)이 나를 더 쉽게 찾는다.**
2. FCR 페이지와 IHADSS에 표적 목록이 우선순위 순으로 뜬다(대공 위협 > 전차 > 장갑차 > 차량). `Tab`으로 표적 순환.
3. 발사하면 미사일이 스스로 유도한다. 즉시 숨어도 된다.
4. 단점: 레이더는 식별을 못 한다 — FCR 표적에는 **"바퀴/궤도/방공" 분류만** 뜨고 아군·민간 구별은 TADS로 확인해야 한다. 확인 안 된 표적에 쏘다 민간 차량을 맞히면 감점.

### 스팅어 — 공대공
1. `무장 선택: 스팅어` (키 `4`). 헬멧 시선을 공중 표적에 둔다.
2. 적외선 탐색기가 1.5초 동안 표적을 보면 잠금 톤(높은 음)이 난다 → 발사.

## 4.4 센서

### IHADSS (헬멧 심볼)
현재 `src/sim3d/ihadss.ts`가 구현하고 있는 헬멧 심볼 위에 무장·위협 심볼을 추가한다. 화면 명세는 07장 7.4절. 원칙: IHADSS는 **머리를 돌려도 화면에 고정**되며, 월드 고정 요소(수평선, 표적 마름모)는 투영해서 그린다(현재 방식 유지).

### TADS (표적 획득·지시 장치)
- 기수 아래 센서 터릿(현재 모델에 있음, 좌표 `(0, -0.72, -6.55)`)에 두 번째 카메라를 둔다.
- **TADS 모드**(키 `T`): 전체 화면이 TADS 영상으로 바뀐다. 조종석은 안 보인다. 7장 7.5절 화면.
- 시야각(FOV) 단계: 광각 30° / 중간 10° / 협각 3° / 초협각 1° (마우스 휠·키 `+`/`-`). 방위 ±120°, 고각 +30°/−60°.
- 조작: 마우스 이동·오른쪽 스틱·터치 드래그로 시선 이동(협각일수록 느리게).
- 모드: **주간 TV**(컬러를 흑백 대비 강화), **FLIR 열상**(흰색=뜨거움: 엔진이 켜진 차량·보병은 밝게, 지형은 어둡게). 야간 임무에서는 FLIR만 쓸 수 있다.
- 렌더: 별도 `WebGLRenderTarget`에 렌더 후 셰이더로 흑백/열상 변환. 해상도는 화면의 절반. **TADS 모드가 아닐 때도** TADS 페이지를 MPD에 띄우면 작은 해상도(256×256)로 5fps 렌더해 MPD 화면 텍스처로 쓴다.
- 식별: 협각(3° 이하)에서 표적을 1초 이상 조준 십자 안에 두면 유닛 분류가 확정되어 표적 정보창에 **유형과 아군/적/민간**이 뜬다. 보조 옵션 "자동 식별"을 켜면 광각에서도 즉시.
- 레이저 측거·지시: 키 `L`. 레이저 점이 닿은 지형·유닛까지 거리 표시.
- 구현 세부(M2-4): 시선 각도(`az`, `el`)는 기체 기준이며 영상은 수평선이 기울지 않게 세운다. 줌 단계에 비례해 시선 이동이 느려진다(1°에서 30°의 1/30). TADS 모드 중 `V`는 외부 시점 대신 주간/열상 전환. 기관포 조준은 TADS 모드에선 머리 대신 TADS 시선을 따른다. 조종 인계 자동 호버(`src/sim/heli/autohover.ts`)는 지면 속도가 2m/s를 넘으면 먼저 멈추고, 그 뒤 들어간 지점의 위치·고도·기수를 PID로 유지한다(바람 항력은 앞먹임으로 상쇄, 10초 이동 < 2m 테스트). 착지 중이면 손대지 않는다. TADS 영상은 안개를 2.5–9km로 넓혀 멀리까지 보인다. MPD의 TADS 축소판(256×256, 5fps)은 MPD 페이지 작업(M2-7)에서 붙인다.

### FCR (화력 통제 레이더, 롱보우 돔)
- 임무 6부터. 레이더 돔 모델은 이미 있다.
- 스캔: 전방 ±45°(지상 표적 모드) 또는 360°(공중 표적 모드), 최대 8km, 가시선 필요(지형에 가린 유닛은 안 보임). 한 번 스캔에 3초.
- 결과: 최대 16개 표적, 분류(바퀴/궤도/방공/헬기/고정익), 우선순위. 스캔 후 표적 위치는 **스캔 시점 기준**(움직이는 표적은 오차 누적 — 30초 지나면 목록에서 흐려짐).

### 생존 장비
- **RWR (레이더 경보 수신기)**: 레이더를 쓰는 적(자주대공포, SAM)의 상태를 보여 준다: `탐색`(작은 기호) → `추적`(깜박임, 경고음) → `발사`(큰 경고음 + 음성 "MISSILE LAUNCH"). MPD의 ASE 페이지와 IHADSS 가장자리에 방향 표시.
- **미사일 접근 경보 (CMWS)**: 적외선 미사일(휴대용 SAM)은 레이더 신호가 없으므로 **발사 후 접근하는 미사일**만 감지. 음성 "MISSILE, MISSILE" + 방향.
- **플레어**: 30발. 적외선 미사일 기만. 1회 사용 시 2발 투하, 기만 확률 = 60% (미사일이 이미 1km 이내면 30%). 자동 모드(보조 옵션): 미사일 경보 시 자동 투하.
- **채프**: 30발 (임무 4 해금). 레이더 추적·레이더 유도 미사일 기만, 확률 50%, 사용 시 레이더 추적이 2초 끊김.
- 가장 확실한 회피는 **가시선을 끊는 것**이다. 대응책은 보조 수단으로 밸런스를 잡는다(P2).

## 4.5 무장 관련 입력 요약

| 동작 | 키보드·마우스 | 게임패드 | 터치 |
| --- | --- | --- | --- |
| 무장 순환/선택 | `1`–`4`, `Q` 순환 | 십자키 좌/우 | 무장 버튼(탭하면 순환) |
| 발사 | `Space` / 좌클릭 | RT | 발사 버튼 |
| TADS 모드 | `T` | 십자키 위 | TADS 버튼 |
| 레이저 | `L` (누름 유지) | LT | 레이저 버튼 (누름 유지) |
| TADS 줌 | 휠 / `+` `-` | LB/RB | 두 손가락 핀치 |
| FCR 스캔 | `R` | 십자키 아래 | FCR 버튼 |
| 표적 순환 | `Tab` | Y | 표적 버튼 |
| 플레어 / 채프 | `F` / `X` | B / X | 대응책 버튼 (플레어 우선) |

`R` 키는 지금 "다시 시작"에 쓰이고 있다. 전투 모드에서는 재시작을 일시정지 메뉴로 옮기고 `R`을 FCR에 준다(7장 조작표).
