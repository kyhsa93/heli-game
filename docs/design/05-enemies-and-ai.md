# 05. 적·아군 유닛과 AI

이 장의 수치가 유닛 밸런스의 원본이다. 구현 시 `src/content/units.json`으로 옮긴다.

## 5.1 유닛 공통 규칙

- 모든 지상·공중 유닛은 **유닛 엔티티**다(08장 8.4절 `Unit`). 공통 속성: `type`, `side`(`coalition` / `veros` / `civilian`), `hp`, `armor`(장갑 등급 0~5), 위치·방향, AI 상태.
- **파괴**: `hp ≤ 0`이면 파괴 상태로 바뀌고 잔해 모델 + 불·연기 효과(30초)로 바뀐다. 잔해는 표적이 아니다.
- **보병**은 개인이 아니라 **분대(4~8명) 단위 엔티티**다. 분대 `hp`가 줄면 표시되는 인원 수가 줄어든다. 사망 연출 없음(인원이 사라짐).
- **렌더**: 유형별 `InstancedMesh`로 그린다(08장 성능 예산). 모델은 **채택된 외부 저폴리 모델**(10장 10.6절 표의 유닛 ID별 매핑)을 쓰고, 로드 후 공용 머티리얼로 바꿔 색을 `units.json`에서 지정한다. 외부 모델이 없는 유형(`bunker`, `ammo_depot`, `hq`, `aaa_light`, `farp` 연료 블래더)과 로드 실패 시에는 코드로 만든 저폴리 도형을 쓴다. 게임 안 이름은 가상 명칭이다.

## 5.4 탐지 모델

P2(지형이 무기다)를 구현하는 핵심 규칙이다.

### 가시선 (LOS)
- 관측자 눈높이(유닛 높이 + 2m) → 플레이어 기체 중심까지 선분을 20m 간격으로 샘플링해 `terrain.heightAt()`과 비교한다. 한 점이라도 지형이 선분보다 높으면 가려짐.
- **나무 차폐**: 선분이 나무 캐노피(반경 `tree.r`, 높이 `tree.y+tree.h`)를 지나면 차폐율 +40% (시각만, 레이더는 무시). 두 그루 이상이면 완전 차폐.
- 구현(M3-1, `src/sim/los.ts`): 캐노피는 나무 높이의 30~100% 구간, 반경 `tree.r`인 원기둥으로 판정한다. 시각은 `visualSight`(지형 + 나무, `occlusion` 0/0.4/1), 레이더는 `radarSight`(지형만). `LosCache`는 관측자·대상이 5m 이상 움직였거나 0.5초 지났을 때만 다시 계산한다. TADS 식별도 같은 시각 가시선을 쓴다(나무 두 그루 뒤 표적은 식별 불가).
- 비용 절약: AI 틱(10Hz)마다, 유닛마다 한 번. 거리 > 해당 유닛 최대 탐지거리면 계산하지 않음. 공간 격자(08장)로 후보만 고른다.

### 시각 탐지
- 각 적 유닛은 플레이어에 대한 **인지도(awareness)** 0~1을 가진다. 1이 되면 "탐지"(교전 가능), 0.3 이상이면 "의심"(그쪽을 쳐다봄).
- 가시선이 있을 때 초당 증가량:
  `rate = base × 거리계수 × 노출계수 × 소음계수 × 조명계수`
  - `base` = 0.6
  - 거리계수 = `clamp(1 - 거리/시각최대거리, 0, 1)^1.5`, 시각최대거리 = 주간 4,000m / 야간 1,500m(탐조등 있는 유닛은 탐조등 방향 2,500m)
  - 구현(M6-4, `src/sim/ai/searchlight.ts`): 탐조등은 별도 유닛 `searchlight`(체력 30, 장갑 0, 5m 탑 위 램프, 파괴 가능). 야간에만 켜진다. 평소엔 기본 방위 ±60°·앙각 10–40°를 14초 주기로 훑고, 헬기가 반각 5° 빔 안·2.5km 안·지형 가시선에 들어오면 비춘 것으로 보고 초당 25°로 따라간다(빔에서 벗어나도 3초간 추적). 비추는 동안 탐조등 800m 안의 적 유닛은 야간 시각 한계 1,500m 대신 2,500m를 쓴다. 렌더는 램프 구 + 가산 혼합 원뿔(1.4km, 램프에서 멀어질수록 흐려짐). 임무 8의 두 대공 진지 옆에 하나씩 두고 보조 목표 '탐조등 2개 파괴'를 더했다.
  - 노출계수: 레이더 고도 기준, 지면 30ft 이하 & 속도 10kt 이하 → 0.35, 그 외 1.0. 스카이라인(기체 뒤가 하늘) → × 1.5
  - 소음계수: 거리 1,500m 이내면 로터 소리로 × 1.5 (가시선 없어도 "의심"까지는 올라감, 초당 0.1)
  - 조명계수: 안개 × 0.5
- 가시선이 없으면 초당 −0.15로 떨어진다. 한 번 탐지한 유닛은 마지막으로 본 위치를 20초 기억하고 그쪽을 경계한다.
- **경계 전파**: 탐지한 유닛은 반경 1,000m의 같은 편 유닛 인지도를 즉시 0.5로 올린다(무전). 팝업 위치를 바꿔야 하는 이유.

### 레이더 탐지
- 레이더 유닛(`spaag`, `sam_short`, `sam_radar`)은 시각 대신 레이더 규칙을 쓴다: 가시선 + 탐색 거리 안 + **지면 클러터**: 플레이어 레이더 고도 < 50ft면 탐지 확률 틱당 5%, 그 외 50%. 탐지되면 `탐색 → 추적`으로 가는 데 2초(RWR에 `추적` 표시), 추적 중 사거리 안이면 발사.
- 플레이어가 FCR을 쓰면 그 스캔 동안 레이더 유닛의 탐지 확률 100%.
- 구현(M3-2, `src/sim/ai/awareness.ts`): World가 10Hz로 `stepAwareness`를 돌린다(적 편 `veros`만, `detect: none` 제외). 관측자 눈 = 유닛 높이 + 2m. 나무 차폐율만큼 증가량이 줄어든다(× (1 − occlusion)). 스카이라인은 관측자→플레이어 선을 3km 연장해 지형이 선 위로 안 올라오면 적용. 로터 소음 의심은 가시선이 없을 때 0.3까지만. 인지도 1이 되면 `detected` 이벤트, 레이더는 `search → acquire(탐지) → track(2초 뒤, 추적 거리 안)`이고 `track` 진입·해제 때 `radarTrack` 이벤트(RWR·발사는 M3-5·M3-6). 조건(`world.conditions`: 야간·안개·플레이어 레이더 방사)은 임무·시간대 작업이 채운다.

## 5.5 AI 상태 기계

모든 전투 유닛은 같은 상태 기계를 쓰고, 유형별로 파라미터만 다르다.

```
            인지도≥0.3          인지도≥1 & 사거리 안
  [대기/이동] ─────────→ [경계] ─────────────────→ [교전]
      ↑   (경로 따라감)    │ 목표 방향 쳐다봄        │ 조준 → 사격
      │                   │ 20초 동안 못 보면        │
      │ ←─────────────────┘                          │ 가시선 끊김 3초
      │                                              ↓
      │                                          [수색] 마지막 위치 주시 20초
      │ ←────────────────────────────────────────────┘
      │
  HP < 30% & 이동 가능 → [후퇴] 가장 가까운 엄폐(숲·건물) 쪽으로 이동
```

- **조준 지연(반응 시간)**: 교전 상태 진입 후 첫 사격까지 유형별 지연 — 보병 2초, 차량 1.5초, 대공포 1초, SAM 3초(잠금 시간).
- **명중률**: 기본 명중률 × `(1 - 거리/최대사거리)` × 플레이어 속도 보정(속도 60kt 이상이면 × 0.6) × 난이도 배율. 명중 판정은 발사체를 실제로 날리는 대신 **확률 판정 + 연출용 예광탄**으로 한다(적 소화기 탄까지 발사체로 시뮬레이션하면 비용이 큼). 단, **미사일(SAM, MANPADS, 적 공대공)은 실제 유도 엔티티**로 날려서 대응책·회피가 의미 있게 한다.
- 구현(M3-3, `src/sim/ai/brain.ts`): 직사 무장(`bullet`·`rocket`)마다 `units.json`에 **기본 명중률 `accuracy`**(발당, 0.06~0.15)를 둔다. 발사율만큼 `fire` 이벤트(연출 예광탄, 빗나간 탄은 거리에 비례해 흩어짐)를 내고, 명중이면 `playerHit {by, weapon, damage}` 이벤트를 낸다(피해 적용은 M3-4). 탐지 뒤 사거리 밖이면 경계에 머문다. 수색 중 다시 보이면 반응 시간의 절반 뒤 사격. 후퇴 엄폐는 600m 안의 가장 가까운 나무(위협 반대쪽)나 건물로 직선 이동(도로·A*는 M4-4). 고정 진지·헬기는 후퇴하지 않는다. 훈련 표적은 `passive`로 스폰해 인지·교전하지 않는다. `world.difficulty`의 배율 자리만 만들어 두고 값은 M3-9에서 채운다.
- 밸런스(M7-6): 명중률의 거리 감쇠를 `1 − 거리/사거리`에서 `1 − (거리/사거리)²`로 바꾸고, 기관포 계열의 발당 명중률·피해를 올렸다 — 대공포 0.26·16, 자주대공포 0.22·20, 기관총 차량 0.26·10, 기관총 사수 0.15·2.5, 적 헬기 기관포 0.22·10. 이전 값으로는 탁 트인 곳에 호버한 채 자주대공포 2km 앞에 60초를 버텨도 격추되지 않아 P2(지형이 무기다)가 성립하지 않았다. 지금은(보통 난이도, 사격 시작부터) 자주대공포 1km 약 15초·2km 약 30초, 대공포 1.5km 약 45초, 기관총 차량 800m 약 110초 만에 격추되고, 자주대공포 2km 앞 5초 팝업은 대개 계통 손실 없이 넘긴다. 이 두 성질은 `src/content/balance.test.ts`가 지킨다. 사람 플레이테스트로 다시 맞출 것(#83).
- **적 미사일 유도**: 비례항법(N=3), 최대 기동 25g, 연료 연소 후 속도 감소. 표적 가시선이 끊기면(지형) 적외선 미사일은 2초 후 유도 상실, 레이더 미사일은 즉시 유도 상실.
- 구현(M3-5, `src/sim/weapons/enemyMissile.ts`): 미사일 제원은 `weapons.json`(`sa_ir`, `sam_radar`, `heli_aam`: 최고 속도, 연소 시간, 항력, 최대 비행 시간, 근접 신관 반경 6~10m). 연소 중엔 최고 속도까지 가속, 연소 뒤 항력으로 감속하고 유도가 끊기면 중력만 받는다. 적외선은 미사일→표적 지형 가시선이 2초 넘게 끊겨야 유도 상실(그 전에 다시 보이면 계속 추적 — 숨을 땐 미사일이 솟아도 안 보일 만큼 깊이), 레이더는 발사대 레이더나 미사일의 가시선이 끊기는 즉시 상실. 근접 신관이 터지면 `blastPlayer`로 계통에 분배. 발사 때 `missileWarning {kind, from}`(CMWS·RWR용), 끝날 때 `missileEnd {hit}`. 교전 중인 유닛은 조준 지연 뒤 사거리 안이면 쿨다운(1/rate)마다 발사하고, 레이더 미사일은 레이더 `track` 상태가 필요하다.
- 구현(M3-7): 대공 유닛 흐름 — 자주대공포는 레이더 탐지 → 2초 뒤 추적 → 기관포 2.5km, 단거리 SAM은 추적 중이고 정지해 있을 때만 레이더 미사일, 휴대용 SAM·대공 진지·기관총 차량은 시각 탐지 → 반응 시간 → 사격/미사일. SAM 레이더 기지(`sam_radar`)는 6km 안 같은 편 `sam_short`와 연동된다: 기지가 표적을 잡고 있으면 발사대는 지면 클러터 확률 없이 바로 탐지하고, 연동된 기지가 모두 파괴되면 발사대 탐색 거리가 절반이 된다. 기지 자체는 추적 거리가 0이라 `track`에 들어가지 않는다(RWR엔 탐색으로만 보임). 모델은 코드(`src/render/airDefenseModels.ts`); Pantsir·UAZ 외부 모델은 #65 결정 대기.

- 구현(M4-4, `src/sim/ai/movement.ts`): 도로 폴리라인의 점을 2m 안이면 한 노드로 합쳐(T자 교차 포함) 그래프를 만들고, 그룹 `route` 점들을 가까운 노드끼리 A*로 이어 실제 주행 경로로 바꾼다(도로가 없는 지도에선 경로 점을 그대로). 행동: `hold`·`defend`는 제자리, `advance`는 끝까지 한 번, `patrol`은 끝에서 되돌아오거나 `loop`면 처음으로, `convoy`는 앞 차량과 경로 거리 25m 간격을 유지하며 교전 중에도 계속 달린다(다른 행동은 교전 중 정지). `startTrigger`가 있는 그룹은 그 트리거가 발동할 때까지 대기. 도로 밖(도로 12m 밖) 야지 유닛은 오프로드 속도로, 진행 방향이 20°보다 가파르거나 물이면 ±30°·60°·90°로 틀어 보고 막히면 선다. 공중 유닛은 경로를 지형 위 60m로 직선 비행(표적 주위 선회는 적 헬기 작업 M5-4). 이동은 물리 스텝마다 갱신한다.
- 구현(M5-4, `src/sim/ai/air.ts`): 적 헬기는 평소엔 그룹 경로를 따르고, 교전(`engage`)에 들어가면 플레이어를 중심으로 반경 1,200m(기관포 1,500m 안) 원을 45m/s로 돈다 — 유닛 ID 홀짝으로 도는 방향이 다르고, 멀면 원 쪽으로 파고들며 최대 70m/s까지 빨라진다. 고도는 지형 위 60m, 기수는 플레이어를 향한다. 사격은 지상 유닛과 같은 통계 사격(기관포·로켓). 적외선 공대공은 유닛 스폰 옵션 `aam: true`(임무 JSON 유닛 필드, 임무 11부터 쓸 것)일 때만 쏜다. 격추되면 속도를 이어받아 중력으로 떨어지고 땅에 닿을 때 폭발(크기 8). 수색·경계로 돌아가면 다시 그룹 경로.

## 5.6 AI 구현 지침

- AI는 `src/sim/ai/` 에 순수 TS로. 렌더·DOM 의존 금지.
- AI 틱 10Hz(물리 120Hz 중 12스텝마다). 유닛을 10개 그룹으로 나눠 틱마다 한 그룹씩 갱신하지 말고, **모든 유닛을 10Hz로 갱신하되 LOS 계산은 캐시**(플레이어가 5m 이상 움직였거나 0.5초 지났을 때만 재계산).
- 결정론: AI의 모든 무작위는 월드 RNG(`world.rng`)에서 뽑는다. 같은 시드 + 같은 입력 → 같은 결과. 테스트가 이것에 의존한다.
- 테스트 예시(각 항목이 테스트 하나): 능선 뒤에 숨은 플레이어는 탐지되지 않는다 / 30ft 호버는 같은 거리 고공 호버보다 늦게 탐지된다 / 대공포는 가시선이 끊기면 3초 안에 사격을 멈춘다 / 플레어는 적외선 미사일을 설정 확률로 기만한다(시드 고정 1,000회 시행에서 55~65%).
