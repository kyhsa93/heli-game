# 01. 비전

> 전장 모드 기준 1차 개정(B1-16, 2026-09-30). 상세 기획의 기준은 저장소 위키 [01-비전](https://github.com/kyhsa93/heli-game/wiki/01-비전)과 [소유자 결정](https://github.com/kyhsa93/heli-game/wiki/11-소유자-결정)이다. 이 장은 코드 작업자가 먼저 알아야 할 요약만 담는다.

## 1.1 콘셉트

**게임**: 아파치: 카르다 전선 — 봇과 함께 혼자 하는 배틀필드식 대규모 전투, **전장 단일 모드**. 캠페인·훈련·즉시 출격은 없다. 타이틀은 `전장 · 설정 · 크레딧`.

**판타지**: "카르다 계곡 전체가 싸우고 있고, 나는 그 전장의 한 사람이다." 연합군과 베로스 인민군(VPA)이 거점을 놓고 싸우고, 플레이어는 진영을 골라 출격한다. 죽으면 티켓을 내고 10초 뒤 다시 나간다. 전선은 봇이 만들지만 어느 거점이 넘어가는지는 플레이어가 바꾼다.

**플랫폼**: 웹 브라우저(데스크톱·모바일), 설치형 PWA(항상 네트워크에서 받음, 캐시 없음). 키보드+마우스, 게임패드, 터치를 모두 지원한다.

## 1.2 기둥

| 기둥 | 뜻 | 금지 |
| --- | --- | --- |
| **P1′ 탈것마다 제 손맛** | 무엇을 모느냐에 따라 조작·시점·조준이 확실히 다르다. 아파치 조종석·IHADSS·TADS는 그대로 | 모든 탈것이 같은 공용 조작 |
| **P2 지형이 무기다** | 능선·숲·건물·거리가 생존을 가른다. 모든 유닛이 가시선으로 발견·교전 | 가시선 무시 자동 조준, 벽 너머 표식 |
| **P3′ 발견이 곧 화력** | 적은 누군가 발견해야 보인다. 식별·레이저 지시는 팀의 무기 | 적 전원이 항상 미니맵에 보이는 것 |
| **P4′ 한 생애가 한 출격** | 스폰 → 교전 → 사망이 한 호흡. 티켓·탄약·연료는 유한 | 무한 재시작·무적 |
| **P5 싸움을 고른다** | 어디서, 무엇으로 싸울지는 플레이어의 결정 | 한 가지 정답 병과·동선 |

## 1.3 지금 만들어진 것 (B1)

- 하레크 계곡(원점 대칭 지형) **빠른 점령전**(거점 A·D·G, 티켓 200, 제한 15분), 연합 진영, 탈것은 아파치 하나.
- 봇: 양 진영 지상군(소총·대전차·기관총·대공조·저격조 분대, 전차·장갑차·경차량·트럭·방공 차량) — 표적 선택, 통계 사격, 소대·지휘관, 30초 파도 스폰.
- 전장 HUD(티켓·거점·미니맵·발견된 적 표식·처치 알림), 깃발 기둥, 배치·경기 후 보고, 첫 경기 코치.
- 봇만의 경기 중앙값 약 12분, 플레이어 무입력 승률 30~40%, 대리 헬기 승률 100%(하니스, [docs/battle/baseline.md](../battle/baseline.md)).

## 1.4 대상과 성공 기준

- **주 대상**: 배틀필드식 전장을 브라우저·모바일에서 혼자 즐기고 싶은 사람. 첫 실행이 곧 첫 전장이다.
- **부 대상**: 모바일 10분 — 빠른 점령전.

| 기준 | 목표 | 측정 |
| --- | --- | --- |
| 한 판 길이 | 점령전 18~28분, 빠른 점령전 8~12분 | `npm run battle:harness` 20시드 |
| 플레이어 없이도 전장이 돈다 | 플레이어 무입력 승률 30~50% | 하니스(양 진영) |
| 플레이어가 전황을 바꾼다 | 대리 조종사 투입 시 승률 ≥ 60% | 하니스 |
| 첫 경기가 무력하지 않다 | 첫 빠른 점령전에서 적 1명 이상 처치·거점 1회 이상 점령 참여 | 소유자 플레이테스트 |

## 1.5 톤과 설정 원칙

- 가상 국가(카르다 계곡, 연합 신속대응군, 베로스 인민군). 실존 표식·국기는 넣지 않는다.
- 민간인·민간 차량은 전장에 없다. 아군 오사는 감점.
- 사용자에게 보이는 글은 한국어. 상태는 색만이 아니라 모양·글자로도 구분한다(■ 연합 · ▲ VPA · ○ 중립 · × 교전 중).
