# 01. 비전

## 1.1 콘셉트

**작업 제목**: 아파치: 카르다 전선 (Apache: Karda Front)

**장르**: 1인칭 공격 헬리콥터 전투 시뮬레이션 — "심 라이트(sim-lite)". 진짜 조종석과 진짜 절차의 *느낌*을 주되, 보조 기능으로 누구나 비행하고 싸울 수 있게 한다.

**플랫폼**: 웹 브라우저(데스크톱·모바일), 홈 화면 설치형 PWA. 키보드+마우스, 게임패드, 터치를 모두 1급으로 지원한다. 설치나 로그인 없이 링크 하나로 시작한다.

**판타지**: "나는 아파치 조종사다." 좁은 탠덤 조종석, 헬멧에 뜨는 초록 심볼, 능선 뒤에서 살짝 떠올라(bob-up) 적을 찾고, 헬파이어를 쏘고 다시 숨는 긴장감. 로터 소리와 경고음, 연료와 탄약이 줄어드는 압박.

## 1.2 디자인 기둥

모든 기능 결정은 아래 네 기둥 중 하나 이상을 강화해야 한다. 어느 기둥에도 기여하지 않는 기능은 넣지 않는다.

| 기둥 | 뜻 | 이 기둥이 요구하는 것 | 이 기둥이 금지하는 것 |
| --- | --- | --- | --- |
| **P1. 조종석 안에 있다** | 모든 정보는 조종석의 실제 장치(IHADSS, MPD, EUFD, 경고음)를 통해 온다 | 화면 오버레이 대신 헬멧 심볼·MPD 페이지로 정보 전달. 외부 시점은 보조 | 조종석과 무관한 게임식 UI(체력바, 미니맵 위젯, 적 머리 위 이름표) |
| **P2. 지형이 무기다** | 능선·계곡·나무 뒤에 숨는 것이 생존과 승리의 핵심 | 적 탐지는 가시선(LOS) 기반. 낮게 날수록 안전. 팝업 공격이 가장 강한 전술 | 고공에서 원거리로 모든 적을 처리할 수 있는 밸런스 |
| **P3. 찾고, 식별하고, 쏜다** | 교전은 탐지 → 식별 → 조준 → 발사 → 평가 순서를 밟는다 | TADS 줌으로 표적 확인, 아군·민간 오사 처벌, 무장별 다른 조준 절차 | 화면에 적 위치 자동 표시, 버튼 하나로 자동 조준 발사(보조 옵션 제외) |
| **P4. 한 번의 출격이 한 편의 이야기** | 출격 전 준비 → 비행 → 교전 → 귀환이 하나의 호흡 | 브리핑, 무장 선택, 연료·탄약 관리, 피해 누적, FARP 귀환, 디브리핑 | 임무 중간 무한 재시작, 탄약·연료 무한, 무적 |

## 1.3 대상 플레이어

- **주 대상**: 헬기·비행 게임을 좋아하지만 DCS 같은 하드코어 심의 진입 장벽은 부담스러운 사람. 20~40분 단위로 한 출격을 즐긴다.
- **부 대상**: 모바일에서 짧게(5~10분) 즐기는 사람. 즉시 출격 모드와 공중 시작 옵션이 이들을 위한 것.
- **고려 대상**: 하드코어 팬. 보조 기능을 모두 끄면 시동 절차부터 오토로테이션까지 실제에 가까운 경험이 나오도록 한다.

## 1.4 톤과 설정 원칙

- **가상의 전쟁**이다. 실존 국가·정치 세력·실제 분쟁을 쓰지 않는다. 장비는 실제 계열(예: 자주대공포, 단거리 지대공미사일)을 모티브로 하되 가상 명칭을 쓴다.
  - 아군: **연합 신속대응군** (Coalition Rapid Response Force, 약칭 연합군)
  - 적군: **베로스 인민군** (Veros People's Army, 약칭 VPA) — 가상의 국가 "베로스"의 군
  - 전장: **카르다 산맥** — 계곡, 호수, 마을, 도로가 있는 가상의 산악 국경 지대
- **절제된 사실주의**. 폭발과 파괴는 보여주되 인명 피해를 과장하지 않는다. 보병은 소대 단위 추상화(작은 인형 무리)로 표현하고 사망 연출은 없다.
- **민간인 보호는 규칙이다.** 민간 차량·건물 피해는 점수 감점과 임무 실패 조건이 된다. 전쟁을 미화하는 문구, 잔혹 행위 연출은 넣지 않는다.
- 무전 대사는 짧고 건조한 군사 교신체. 콜사인: 플레이어 **"하운드 1"**, 윙맨 **"하운드 2"**, 지휘소 **"카르다 컨트롤"**, 지상 통제관 **"스틸 6"**.

## 1.5 범위

### 들어가는 것 (1.0 목표)
- 12개 임무 캠페인 (3막), 훈련 5개, 즉시 출격
- 무장 4종(30mm 기관포, 70mm 로켓, 헬파이어 레이저 유도, 헬파이어 레이더 유도), 대응책(플레어·채프)
- 적 유닛 12종, 아군 유닛 6종
- TADS 센서 화면(주간·열상), FCR 레이더, RWR·미사일 경보
- 피해 모델(엔진·로터·유압·센서·연료)
- 주간·야간·안개, 바람
- 한국어 UI (문자열은 한 파일로 모아 두고 영어 추가 가능하게)

### 들어가지 않는 것
- 멀티플레이어, 온라인 순위표, 계정
- 자유 비행(목표 없는 샌드박스) 모드, 무적·무한 탄약·무한 연료 모드 (소유자 결정)
- 다른 기종 조종 (아파치만)
- 사전 녹음 음성 더빙 (무전은 자막 + 합성 효과음, 경고 음성은 선택적으로 브라우저 음성 합성)
- 실제 지도 데이터, 실존 부대·지명
- 과금, 광고

## 1.6 성공 기준

- 처음 온 사람이 훈련 1(이륙·호버·착륙)을 **5분 안에** 끝낸다 (보조 기능 기본값).
- 캠페인 임무 하나가 **15~30분**, 즉시 출격이 **5~10분**.
- 중급 모바일 기기(가로 화면)에서 **30fps 이상**, 데스크톱에서 **60fps**.
- 플레이테스트에서 "지형 뒤에 숨었다가 튀어나와 쏘는" 행동이 가르치지 않아도 두 번째 임무 안에 나타난다 (P2가 작동한다는 증거).
