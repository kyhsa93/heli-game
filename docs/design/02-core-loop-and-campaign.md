# 02. 핵심 루프와 캠페인

## 2.1 핵심 루프

```
 ┌──────────── 출격 루프 (한 임무, 15~30분) ────────────┐
 │                                                      │
 │ 브리핑 → 무장·연료 선택 → 시동/이륙 → 이동(NOE)       │
 │   → 탐색(TADS/FCR) → 식별 → 교전 → 회피·피해 관리      │
 │   → (FARP 재보급 → 재출격)* → 귀환·착륙 → 디브리핑     │
 │                                                      │
 └──────────────────────────┬───────────────────────────┘
                            ▼
 ┌──────────── 캠페인 루프 (12임무) ─────────────────────┐
 │ 결과 → 전선 이동·다음 임무 해금 → 새 무장·능력 해금     │
 │   → 평점·훈장 → 다음 작전 선택                         │
 └──────────────────────────────────────────────────────┘
```

### 교전 미시 루프 (30초~2분, 게임의 심장)

1. **숨는다**: 능선 뒤 30ft 이하로 호버. 적은 나를 못 본다.
2. **떠오른다(bob-up)**: 콜렉티브를 올려 능선 위로 머리만 내민다. 이때부터 가시선 안의 적이 나를 탐지하기 시작한다(탐지 게이지, 05장).
3. **찾는다**: TADS로 줌하거나 FCR을 한 번 돌린다. 표적이 목록에 뜬다.
4. **식별한다**: TADS 영상에서 전차/트럭/민간차량/아군을 구별한다(보조 옵션 켜면 자동 표시).
5. **쏜다**: 헬파이어(레이저면 명중까지 조준 유지), 로켓, 기관포.
6. **숨는다**: 경보(RWR, 미사일 경보)가 뜨면 즉시 하강해 가시선을 끊는다. 대응책 사용.
7. 이동해서 다른 위치에서 반복한다. 같은 자리에서 두 번 떠오르면 적의 경계가 올라가 있다(탐지가 빠름).

## 2.2 게임 모드

| 모드 | 목적 | 시작 상태 | 저장 |
| --- | --- | --- | --- |
| **캠페인** | 주 콘텐츠. 12개 임무, 3막 | 임무 정의대로 (대부분 FARP에서 시동 꺼진 상태, 옵션으로 공중 시작) | 진행·평점·해금 저장 |
| **훈련** | 비행·무장·센서·생존 학습 | 훈련별 지정 | 완료 여부 저장 |
| **즉시 출격** | 5~10분 짧은 교전. 모바일 대상 | 공중 시작, 표적 지역 3km 앞 | 최고 점수만 |

즉시 출격 구현(M4-9, `src/sim/mission/instant.ts`): 시드·위협 수준·시간대로 `MissionDef`를 만든다. 8km 지도, 평지 표적 군집 1~2곳(서로 1.2km 이상), 군집마다 위협 수준별 표적(낮음: 트럭·기관총 차량·보병 / 보통: + 장갑차·전차 / 높음: 전차 둘·장갑차 둘…)과 대공(낮음: 기관총 차량 / 보통: + 대공 진지·휴대용 SAM / 높음: 대공 진지·자주대공포·휴대용 SAM·뒤쪽 1.4km 단거리 SAM), 근처 민간 차량 1대. 첫 군집에서 지도 중심 쪽 3km 공중(60m, 60kt)에서 시작, 그 뒤 1.5km에 FARP, 군집 앞 좌우에 BP 2곳. 목표는 군집별 표적 70% 파괴(주 목표), 착륙 없이 끝난다(`kind: instant`). par는 1000 + 적 점수 합의 70% + 400. 최고 점수만 `localStorage`(`heli-instant-best`)에 남는다. 시간대는 주간만 열려 있고 나머지는 M6에서. 활성 이동 목표가 없으면 BP가 아닌 첫 웨이포인트(표적 지역·교량·목적지)가 항법 목표가 된다.

> 결정됨: **자유 비행 모드와 무적(무한 탄약·연료) 모드는 만들지 않는다.** 지금의 "보급품 운송" 규칙은 M0에서 **훈련 T1(기본 비행)** 으로 바뀐다 — 패드 A 이륙 → 패드 B 착륙이라는 뼈대가 같다. 기지 패드의 연료 보급 규칙은 FARP 재급유(6장 6.5절)로 이어진다. 탄약·연료가 넉넉해야 하는 훈련은 무한 모드 대신 **훈련 임무 JSON에서 탄약·연료를 충분히 지정**한다.

| T5 | 생존 | RWR 읽기, 지형 차폐, 플레어·채프 | 대공 위협 구역 통과 후 착륙, 피격 2회 이하 |

구현 메모(M4-8에서 JSON으로 이전 — `src/content/missions/t*.json`, 지도는 고정 시드 4km. 아래 M2-8·M3-10 메모의 규칙은 같은 동작을 트리거로 옮긴 것이다):

구현 메모(M2-8):
- 훈련은 화면 가운데 한 줄 **단계 지시**를 띄운다(`Objective.step` → `training.<id>.steps.<step>` 문자열, 07장 7.9절의 초기형).
- T3: 사격장 패드 주변 연성 표적 5개(기관포 단계)와 그 너머 320m의 표적 무리 5개(로켓 단계). 기관포로 3개를 부수면 로켓 단계로 넘어가고 항법 목표가 "로켓 표적 구역"으로 바뀐다. 합계 7개 파괴로 완료. 로드아웃은 기관포 1,200 + 바깥 파일런 로켓 포드 2개. 장갑 표적은 넣지 않았다 — 로켓 관통 2가 장갑 3 이상에 ×0.1이라 로켓 훈련으로 맞지 않는다(장갑은 T4 헬파이어).
- T4: 기지에서 가장 먼 패드 근처 전차 4대, 헬파이어 8발(안쪽 파일런), 공중 시작. 시작점에서 전차가 보이도록(가시선 여유 0.4m) 고도를 올리고, 그래도 안 보이는 전차는 패드 주변 보이는 자리로 옮긴다. 단계: TADS 켜기 → 식별 → LOBL → 나머지(LOAL 안내). **유도 중인 미사일의 레이저가 끊기면(점 상실) 즉시 훈련 실패**(`objective failed`, 사유 `laserBreak`). 결과에 발사 수와 LOAL 명중 수를 보여 준다.
- T5: 기지 → 가장 먼 패드 경로의 40~72% 지점 좌우에 자주대공포·휴대용 SAM·기관총 차량·단거리 SAM을 둔다(교전하는 실제 적). 경로 끝 250m 앞 공중에서 시작하지 않고 기지 쪽 끝에서 출발한다. 피격(직사 명중 또는 미사일 폭발)이 2회를 넘으면 즉시 실패(`tooManyHits`), 목표 패드에 착륙하면 완료. 단계: 처음 8초 RWR 읽기 → 저고도 차폐 → (미사일이 오는 동안) 플레어·채프 → 600m 안에서 착륙. 결과에 피격 수와 쓴 플레어.

## 2.3 캠페인 구조

- **3막 12임무**. 막마다 새 메커니즘을 1~2개씩 도입한다. 임무는 선형 해금(n번 완료 → n+1 해금)이 기본이며, 막 안에서는 이미 해금된 임무를 다시 할 수 있다.
- **전선 지도**: 캠페인 지도 화면에 전선이 표시되고, 임무 결과에 따라 전선 표시가 이동한다. 다만 이야기 분기는 없다(결과는 평점과 일부 보너스 목표에만 영향).
- **임무 실패**: 주 목표 실패 또는 기체 손실 시 임무 실패. 재시도 무제한. 캠페인이 막히지 않는다.

## 2.4 점수와 평점

임무가 끝나면 디브리핑에서 점수와 평점(S/A/B/C, 실패 시 F)을 준다.

| 항목 | 점수 |
| --- | --- |
| 주 목표 완료 | +1000 (임무 공통, 목표 수로 나눠 분배) |
| 보조 목표 완료 | 목표마다 +300 |
| 적 격파 | 유닛별 `score` 값 (05장 표) |
| 무장 효율 | (명중 수 / 발사 수) × 300, 헬파이어·로켓만 계산 |
| 피해 없이 귀환 | +200 |
| FARP 또는 기지에 착륙해 임무 종료 | +200 (착륙 못 하고 임무 종료 시 0) |
| 시간 보너스 | 임무별 기준 시간보다 빠르면 초당 +2, 최대 +300 |
| 아군 오사 | 유닛마다 −1000, 3회 이상이면 즉시 임무 실패 |
| 민간 피해 | 차량·건물마다 −500 |
| 기체 손실 | 임무 실패 |

평점 기준: 해당 임무 `par` 점수(임무 JSON에 정의) 대비 S ≥ 100%, A ≥ 80%, B ≥ 60%, C 그 외 성공.

구현(M4-7, `src/sim/mission/scoring.ts`): 위 표 그대로 항목별 줄을 만든다. 무장 효율은 헬파이어(K·L)와 로켓의 발사·명중만 합산(적·민간 유닛 명중, 아군 명중 제외). '피해 없이 귀환'은 성공했고 피격 0회·손상 계통 0개일 때, 착륙 보너스는 한 번 이상 이륙한 뒤 FARP에 착륙한 상태로 끝났을 때, 시간 보너스는 성공했을 때만. 아군 격파 3회째에 즉시 실패(`friendlyFire`). 기체 손실·임무 실패는 F이고 점수 내역은 그대로 보여 준다(캠페인 최고 기록 저장은 M5-1).

## 2.5 진행과 해금

플레이어 경험치 대신 **계급**과 **해금**을 쓴다. 해금은 새로운 전술 선택지를 여는 것이어야 하고, 단순 수치 상승은 넣지 않는다.

| 조건 | 해금 |
| --- | --- |
| 캠페인 시작 | 기관포, 로켓, 헬파이어(레이저) |
| 임무 4 완료 | 채프 (그 전엔 플레어만) |
| 임무 6 시작 | FCR 레이더, 헬파이어(레이더 유도) |
| 임무 8 시작 | 야간 장비(열상 TADS, PNVS) |
| 임무 9 시작 | 스팅어 공대공 미사일 |
| 임무 10 완료 | 윙맨 지시 메뉴 |
| 캠페인 S 평점 6개 | 도색 2종 (외형만) |

계급: 소위 → 중위 → 대위 → 소령. 누적 점수로 오르며 표시용이다.

### 저장 데이터

`localStorage` 키 하나(`heli-campaign-v1`)에 JSON으로 저장한다. 읽기·쓰기는 모두 try/catch로 감싼다(사생활 보호 모드에서 실패해도 게임은 동작). 형식:

```ts
interface CampaignSave {
  version: 1;
  missions: Record<string, { completed: boolean; bestScore: number; bestGrade: 'S' | 'A' | 'B' | 'C' | null }>;
  training: Record<string, boolean>;
  totalScore: number;
  settings: Settings; // 07장 7.8절
}
```

버전이 다르면 이관 함수로 변환하고, 모르는 버전이면 새로 시작한다(데이터를 지우지 말고 `heli-campaign-backup`에 옮긴다).

구현(M5-1, `src/save/campaign.ts`·`src/save/storage.ts`): 형식에 `instantBest: { score, grade } | null`(즉석 임무 최고 기록)을 더했고, `settings`는 `{ difficulty, voiceWarnings, assists: { autoIdentify, autoCountermeasures } }`다. 흩어져 있던 옛 키(`heli-training-done`, `heli-difficulty`, `heli-voice-warnings`, `heli-instant-best`)는 새 키가 없을 때 한 번 읽어 옮긴다. 읽은 JSON의 필드가 깨졌으면 그 필드만 기본값으로 고치고 `totalScore`는 임무별 최고 점수 합으로 다시 계산한다. 해금은 저장 데이터에서 계산한다(`unlockedFor`): 표의 'N 시작'은 'N−1 완료'와 같다. 계급 문턱은 누적 0 / 5,000 / 15,000 / 30,000점. 해금 조건·계급 이름·문턱·임무 순서는 코드가 아니라 `src/content/campaign.json`(M5-2)에 있다.
