# 용어집

| 용어 | 풀이 | 이 게임에서 |
| --- | --- | --- |
| AGL | Above Ground Level, 지면 기준 고도 | 레이더 고도. `sim.agl()` |
| ASE | Aircraft Survivability Equipment, 생존 장비 | RWR·CMWS·대응책 묶음, MPD `ASE` 페이지 |
| BP | Battle Position, 전투 위치 | 능선·숲 뒤 엄폐 호버 지점. 임무 웨이포인트로 표시 |
| Bob-up | 엄폐 뒤에서 수직으로 잠깐 떠올라 관측·사격 후 다시 내려가는 기동 | IHADSS `BOB-UP` 모드 |
| CAS | Close Air Support, 근접항공지원 | 아군 지상군 근처 적을 공격하는 임무 유형 |
| CMWS | Common Missile Warning System, 미사일 접근 경보 | 적외선 미사일 접근을 경고 |
| Collective | 콜렉티브, 로터 전체 피치(출력) 레버 | W/S, 놓아도 유지 |
| CPG | Co-Pilot/Gunner, 앞좌석 사수 | 앞좌석에 앉은 NPC. 플레이어가 TADS 모드로 역할을 대신함 |
| CSAR | Combat Search and Rescue, 전투 탐색 구조 | 임무 7 |
| Cyclic | 사이클릭, 로터 원판을 기울이는 조종간 | 방향키 / 오른쪽 스틱 |
| EUFD | Enhanced Up-Front Display | 계기판 가운데 주황 경고·상태 화면 |
| FARP | Forward Arming and Refueling Point, 전방 재무장·재급유 지점 | 착륙하면 재급유·재무장·수리 |
| FCR | Fire Control Radar, 화력 통제 레이더 (롱보우) | 로터 위 돔. 표적 탐색, 헬파이어 레이더형 유도 |
| FLIR | Forward Looking Infrared, 전방 적외선 열상 | TADS 열상 모드, 야간 필수 |
| FOV | Field of View, 시야각 | TADS 줌 단계 |
| Hellfire (AGM-114) | 대전차 미사일. K형 레이저 유도, L형 레이더 유도 | 주력 무장 |
| Hydra 70 | 70mm 무유도 로켓 | 면 제압 |
| IHADSS | Integrated Helmet And Display Sight System, 헬멧 심볼 시스템 | 초록 심볼 오버레이 (`ihadss.ts`) |
| LOAL | Lock-On After Launch, 발사 후 잠금 | 숨은 채 발사하고 나중에 레이저 비춤 |
| LOBL | Lock-On Before Launch, 발사 전 잠금 | 레이저 비추고 잠근 뒤 발사 |
| LOS | Line of Sight, 가시선 | 탐지·레이저·유도의 전제 조건 (`sim/los.ts`) |
| M230 | 30mm 체인건 | 기수 아래 기관포, 머리 시선 조준 |
| MANPADS | 휴대용 대공미사일 | 레이더 신호가 없어 RWR에 안 뜸 |
| MPD | Multi-Purpose Display, 다기능 화면 | 좌우 초록 화면, 페이지 전환 |
| NOE | Nap-Of-the-Earth, 지형 추종 초저공 비행 | 30ft 이하. 탐지 회피의 핵심 |
| NR | 주 로터 회전수 (%) | `heli.rpm × 101` 표시 |
| PNVS | Pilot Night Vision Sensor, 조종사 야간 열상 센서 | 야간에 IHADSS 영역에 열상 영상 |
| RWR | Radar Warning Receiver, 레이더 경보 수신기 | 탐색·추적·발사 단계 경고 |
| SAS | Stability Augmentation System, 자세 안정 보조 | 현재 비행 모델의 자세 유지 성향. 보조 설정으로 끌 수 있음 |
| SEAD | Suppression of Enemy Air Defenses, 대공망 제압 | 임무 6 |
| SPAAG | Self-Propelled Anti-Aircraft Gun, 자주대공포 | `spaag`. 레이더 대공포 |
| Stinger | 적외선 공대공 미사일 | 임무 9부터 |
| TADS | Target Acquisition and Designation Sight, 표적 획득·지시 장치 | 기수 센서 터릿, TADS 모드 |
| TQ | Torque, 토크 (%) | 엔진 출력 지표. `collective × rpm` |
| TSD | Tactical Situation Display, 전술 상황 화면 | 오른쪽 MPD 지도 페이지 |
| VPA | 베로스 인민군 (가상) | 적군 |
