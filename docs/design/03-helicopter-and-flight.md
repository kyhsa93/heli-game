# 03. 헬리콥터와 비행

## 3.1 현재 비행 모델 (유지)

지금 `src/sim3d/sim.ts`의 `Sim.fly()`에 구현된 모델이 이 게임의 비행 모델이다. 주요 규칙:

| 요소 | 현재 구현 | 값 |
| --- | --- | --- |
| 조종 입력 | `Controls3 { cyclicX, cyclicY, pedal, collective }` | 사이클릭·페달 −1~1, 콜렉티브 0~1(놓아도 유지) |
| 추력 | `MAX_THRUST * collective * rpm² * 지면효과 * 고도한계` | `MAX_THRUST = 1.7g`, 호버 콜렉티브 ≈ 0.59 |
| 자세 | 사이클릭이 목표 자세를 정하고 PD로 따라감(SAS 성격) | 최대 피치 25°, 최대 롤 35° |
| 요 | 페달 → 요 속도, 전진 속도 12m/s 이상에서 선회 자동 협조, 콜렉티브 변화에 따른 토크 요 | |
| 항력 | 기체 축별 선형+제곱 항력, 바람 상대속도 기준 | 최고 속도 약 110kt |
| 로터 회전수 | 엔진 시동 시 스풀업(0→90%에 약 6초), 엔진 정지 시 오토로테이션 | |
| 지면효과 | 바퀴 높이 10m 이하에서 추력 최대 +15% | |
| 착륙 판정 | 하강률 ≤ 3m/s(590fpm), 수평 ≤ 4m/s, 자세 차 ≤ 12°, 경사 ≤ 10° | 어기면 추락 |
| 충돌 | 로터 끝 8점, 동체 13점, 바퀴 3점을 지형·나무·건물과 검사 | 로터 반경 7.3m |

좌표계와 단위(모든 새 코드가 따른다):
- 내부 단위: 미터, 초, 라디안. 표시 단위: kt, ft, fpm(변환 상수 `MS_TO_KT`, `M_TO_FT`, `MS_TO_FPM`).
- 월드 축: `y` 위, `-z` 북쪽(방위 0°), `+x` 동쪽. 방위(도) = `-yaw` 를 도로 바꾼 값(`headingDeg()`).
- 기체 로컬 축: `-z` 기수, `+x` 오른쪽, `+y` 위. 원점은 무게중심(로터 마스트 축 위).
- 물리 고정 간격 `STEP = 1/120`초.

## 3.2 전투용으로 바뀌는 것

### 무게와 성능

무장·연료·탄약이 무게를 만들고, 무게는 호버 여유를 줄인다. **"많이 싣고 나가면 둔해진다"** 는 선택의 무게를 주기 위한 규칙이다.

- 기준 전투 중량 `W0`(빈 무장, 연료 50%) 일 때 지금의 `MAX_THRUST = 1.7g` 을 그대로 쓴다.
- 실효 최대 추력 가속도 = `1.7g × W0 / W`.
- 무게 항목(kg): 빈 기체 5,200 / 연료 100% 1,100 / 30mm 1,200발 350 / 헬파이어 발사대(M299) 60 + 발당 50 / 로켓 포드(M261) 40 + 발당 11 / 스팅어 2발 발사대 45.
- 예: 헬파이어 16발 + 연료 100% + 기관포 만재 ≈ 5,200+1,100+350+4×60+16×50 = 7,690kg. `W0` = 5,200+550 = 5,750 → 실효 최대 추력 ≈ 1.27g (호버 콜렉티브 ≈ 0.79). 느리고 여유 없는 무거운 기체가 된다.
- 연료가 타고 탄약을 쏘면 무게가 실시간으로 줄어든다.

### 연료

- 현재 `fuel` (0~100%)을 유지한다. 연소율: `(0.05 + 0.3 × collective × rpm)` %/초 → 전투 중량에서 약 6~8분 호버. **캠페인용으로 연소율에 0.35 배율**을 곱해 호버 약 20분이 되도록 한다(임무 길이에 맞춤, `content/aircraft.json`의 `fuelBurnScale`).
- 잔량 20% 이하: EUFD "FUEL LOW", 10% 이하: 음성 경고 "BINGO FUEL".

### 보조 기능 (설정에서 켜고 끔)

| 보조 | 기본값 | 동작 |
| --- | --- | --- |
| 자세 안정(SAS) | 켜짐 | 현재 구현 그대로. 끄면 사이클릭이 목표 자세 대신 **각속도**를 명령하고 놓으면 그 자세를 유지(실기에 가까움) |
| 고도 유지 | 꺼짐 | 켜는 순간의 레이더 고도를 콜렉티브 자동 조절로 유지. 콜렉티브 입력이 들어오면 해제 |
| 자동 호버 | 꺼짐 | 속도 5kt 이하에서 켜면 위치 유지(바람 보정). 사이클릭 입력 시 해제 |
| 시동 절차 생략 | 켜짐 | 임무 시작 시 로터가 이미 100% |
| 착륙 판정 완화 | 꺼짐 | 착륙 한계를 1.5배로 |
| 무한 연료·탄약 | 꺼짐 | 훈련·자유 비행에서만 선택 가능 |

보조 기능 구현 위치: `src/sim/heli/assists.ts` (08장 구조). 보조는 **입력을 바꾸는 층**으로만 구현하고 비행 모델 자체는 건드리지 않는다. 즉 `Controls3`를 받아 수정된 `Controls3`를 돌려주는 순수 함수.

## 3.3 피해 모델

체력 막대 하나가 아니라 **계통(시스템)별 상태**를 둔다. 각 계통은 0~100 체력이 있고, 구간에 따라 증상이 생긴다. 이 증상이 "피격되면 어떻게 되나"를 전달하는 수단이다(P1: 경고등과 계기로 알려준다).

| 계통 | 피격 부위(로컬 좌표 영역) | 50 이하 증상 | 0 증상 | 경고 표시 |
| --- | --- | --- | --- | --- |
| 엔진 1 (좌) | 좌측 나셀 | 최대 추력 −15% | 엔진 정지, 최대 추력 −50% (한쪽 엔진) | `ENGINE 1 FIRE` / `ENGINE 1 OUT` |
| 엔진 2 (우) | 우측 나셀 | 동일 | 동일. 양쪽 다 0이면 오토로테이션 | `ENGINE 2 …` |
| 주 로터·변속기 | 마스트·허브 | 진동(카메라 흔들림 증가), `CHIP DETECTOR` | 60초 후 로터 손실 → 추락. 그 전에 착륙해야 함 | `XMSN CHIP`, `LAND NOW` |
| 꼬리 로터 | 꼬리 끝 | 페달 효과 −40% | 요 통제 불능, 기체가 회전. 전진 속도 40kt 이상이면 수직 안정판으로 버틸 수 있음 | `TAIL ROTOR` |
| 유압 | 동체 중앙 | 조종 응답 −30% | 조종 응답 −60%, SAS 꺼짐 | `HYD PRI` / `HYD UTIL` |
| 센서 (TADS/FCR) | 기수 / 마스트 위 레이돔 | 화면 노이즈 | 해당 센서 사용 불가 | `TADS FAIL` / `FCR FAIL` |
| 연료 계통 | 동체 하부 | 누유: 연소율 +100% | 누유: +300% | `FUEL LEAK` |
| 조종석 | 캐노피 영역 | 캐노피 금 (화면에 금 오버레이) | 승무원 사망 → 임무 실패 | `CANOPY` |

- 피격 판정: 탄이 기체 경계 상자에 맞으면, 맞은 로컬 좌표로 계통을 고른다. 폭발 피해(미사일 근접 폭발)는 거리 감쇠로 전 계통에 나눠 준다.
- 기체는 23mm까지 견디도록 설계된 기체다. 소화기(7.62mm)는 발당 피해가 매우 작고, 12.7mm는 작음, 23mm·30mm는 중간, 미사일은 큼. 수치는 05장 무기 표.
- **자동 회복 없음.** FARP에 착륙하면 수리(60초, 모든 계통 100으로) 가능.
- 추락 사유 문자열은 현재처럼 한국어 문장으로 디브리핑에 표시한다.

## 3.4 윙맨

임무 2부터 윙맨 "하운드 2"가 동행하는 임무가 있다(임무 JSON의 `wingman: true`).

- 윙맨은 비행 모델을 쓰지 않고 **경로 추종 AI 기체**다(단순 운동학: 목표 위치로 가속·감속, 지형 위 고도 유지).
- 기본 행동: 플레이어 우측 후방 150m 편대, 플레이어가 공격하는 표적과 다른 표적을 공격.
- 윙맨 지시(임무 10 이후 해금, 7장 무전 메뉴): `편대 유지` / `내 표적 공격` / `자유 교전` / `대공 위협 제압` / `귀환`.
- 윙맨이 격추되면 보조 목표 실패(주 목표는 아님).
