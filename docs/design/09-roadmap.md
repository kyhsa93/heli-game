# 09. 로드맵

## 9.1 원칙

- 마일스톤은 **순서대로**. 각 마일스톤 끝에는 "플레이 가능한 상태"가 있어야 한다(배포해도 되는 상태).
- 작업 ID 하나 = 커밋(또는 PR) 하나 크기. 작업이 너무 크면 `M1-3a`, `M1-3b`로 쪼갠다.
- 각 작업의 **완료 조건**을 모두 만족하고 `npm run check`가 통과해야 체크한다. 렌더·UI 작업은 스크린샷 확인까지(08장 8.8절).
- 작업을 끝내면 이 문서의 체크박스를 `[x]`로 바꾼다.

## 9.2 의존 관계

```
M0 기반 정리 ─→ M1 전투 샌드박스 ─→ M2 센서·유도무기 ─→ M3 위협·생존 ─→ M4 임무 시스템 ─→ M5 캠페인
                                                                              └─→ M6 환경 (M4 이후 병행 가능)
                                                                    M7 완성도 (M5 이후)
```

## 9.3 미정 사항 (소유자 결정 필요)

> 미정: **윙맨의 비중.** 기본안은 "보조 목표 수준의 동료". 캠페인 후반을 윙맨 지휘 중심으로 키울지 결정 필요.

> 미정: **자유 비행 모드 유지 여부.** 기본안은 유지(현재 게임 보존 + 비행 연습). 빼면 `freeflight.ts`와 관련 테스트 삭제.

> 미정: **피해 없는 "아케이드 모드"** (무적 + 무한 탄약) 제공 여부. 기본안은 훈련·자유 비행에서만 무한 탄약.

> 미정: **영어 UI**. 기본안은 한국어만, 단 문자열을 한 파일에 모아 두어 나중에 추가 가능하게.
